# Task Manager

A full-stack task management application with recurring tasks, user authentication, and Supabase database integration.

## Features
- User registration and JWT authentication
- Create, update, delete, and filter tasks
- Priority, due date, and status management
- Recurring tasks automation (daily, weekly, monthly)
- Secure API built with Express, Helmet, Rate Limiting, and CORS
- Supabase PostgreSQL integration

## Tech Stack
- **Frontend**: Vanilla HTML5, CSS3, JavaScript (Fetch API)
- **Backend**: Node.js, Express 5
- **Database / Auth**: Supabase / PostgreSQL & JWT
